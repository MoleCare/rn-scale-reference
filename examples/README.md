# Examples

Complete, copy-paste starting points. CI typechecks every file here against
the package, so they stay in step with the API.

| File                                         | Shows                                                                              |
| -------------------------------------------- | ---------------------------------------------------------------------------------- |
| [`TapToMeasure.tsx`](TapToMeasure.tsx)       | A React Native screen that measures with four taps, no detector needed             |
| [`fromDetector.ts`](fromDetector.ts)         | Turning your detector's ellipse into lengths and areas, with a stricter tilt limit |
| [`compareTwoPhotos.ts`](compareTwoPhotos.ts) | Checking two photos were taken at a similar distance before showing both sizes     |

Every result is an estimate and is shown as one. The examples report numbers
only and never say whether a size or a change matters.
